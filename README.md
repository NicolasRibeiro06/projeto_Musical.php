# 🎵 Sistema Musical PHP

Um sistema web completo desenvolvido em PHP, HTML e CSS para gerenciamento e execução de conteúdos musicais, integrado com banco de dados relacional.

---

## 🚀 Tecnologias Utilizadas

* **Backend:** PHP
* **Frontend:** HTML5, CSS3
* **Banco de Dados:** MySQL / MariaDB

---

## 📌 Funcionalidades

- [x] Conexão com banco de dados via PHP (PDO / MySQLi)
- [x] Listagem e navegação por conteúdos musicais
- [x] Estrutura organizada para expansão de CRUD (Adicionar, Editar, Excluir e Visualizar)
- [x] Interface simples e responsiva com HTML/CSS
